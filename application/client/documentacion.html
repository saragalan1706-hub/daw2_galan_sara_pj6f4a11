About SportMás

SportMás is an order management application for a European sports store chain. Sales staff can create new orders and view existing ones.

How to use it

Create a new order

Fill in the order ID and the customer's details. Check the products you want to add and set the quantity for each one. The total price (VAT included) is calculated automatically and the order is saved.

View all orders

Shows a table with every order stored in the system, including customer details, products and total price.

View one order

Enter an order ID to see the full details of that specific order.
